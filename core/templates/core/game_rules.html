Game Rules

Bets are accepted only during the betting countdown. Cashout requests are validated server-side.

If the server receives cashout before the crash, winnings are credited instantly. Bets still active at crash lose.

Responsible gambling limits, KYC tiers, and self-exclusion controls may restrict play.
